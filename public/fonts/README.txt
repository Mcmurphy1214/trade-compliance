NotoSansSC-Regular.ttf and NotoSansSC-Bold.ttf are static weight instances
of Noto Sans SC, with optional shaping tables removed for predictable,
efficient horizontal Chinese/Latin PDF typesetting. Glyph outlines are retained.
The PDF exporter embeds only glyphs used in the selected briefing.
